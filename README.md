# Local Repository Practice

A small repository used to practice Git, GitHub, and basic web development.

## Contents

- `index.html` — page markup
- `style.css` — page styling

## Run locally

Clone the repository and open `index.html` in a web browser:

```bash
git clone https://github.com/Manishr767/localrepo.git
cd localrepo
```

## Purpose

This is a simple practice repository rather than a complete web application.
